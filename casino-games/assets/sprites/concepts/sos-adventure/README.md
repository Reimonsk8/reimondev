# Square of Shadows — Adventure concept art

PixelLab concept sprites for the planned Adventure mode. These are source art,
not runtime assets: Adventure currently has randomized floors only; monsters,
items, doors, and exploration rules are not implemented.

- `enemies/`: Fallen Templar, Bell Wraith, and Ashen War Hound; four static
  facings each, with no gameplay animation.
- `items/`: Saint's Key, Martyr's Chalice, Blood-Sealed Scroll, and Reliquary
  Shard.
- `landmarks/`: Penitent Altar, Cathedral Gate, and Crypt Descent.

Wire these into the engine only after Adventure's unit, item, and exploration
contracts are defined.
